# ares-mars-route-planner
Mars route planning for the NASA Space Apps Challenge

## Datos

En [`data/`](data/README.md) está la ruta de Curiosity (Gale / Mount Sharp): paradas, trazado, perfil de elevación e índice de fotos por sol. También están documentadas las fuentes en vivo de NASA (teselas de Mars Trek, API de imágenes). Los scripts para regenerarlo todo están en `scripts/`.
