# Archivo del prototipo de Gale

Este material se conserva como referencia histórica del prototipo inicial de Curiosity en Gale / Mount Sharp. La aplicación activa de ARES es la versión Jezero en la raíz del repositorio. No uses estos datos de Gale para el mapa o la cuadrícula Jezero.

Los archivos archivados pueden depender de rutas y utilidades de su aplicación original; no forman parte de la versión activa.
